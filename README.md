# IJK 2028 参加費・予算の検討資料

2026年9月21日更新。京都・亀岡の大本・天恩郷での開催に向けた検討案です。

**まずは[参加費と予算の説明](IJK2028_予算見通し_全日150人_前後半各100人_20260921.md)をご覧ください。**

全日150人・前半100人・後半100人をもとに、宿泊・食事込みの参加費、年齢別料金、協力者の扱い、ホテル泊、日帰り参加、大会全体の収支を説明しています。

**表示する基本料金は「非会員・雑魚寝・食事付き・全日程・25〜35歳」の料金です。** 年齢倍率は16歳以下0.7倍、17〜24歳0.8倍、25〜35歳等倍、36歳以上一律1.5倍。表示基本料金に倍率を掛け、その後で会員割引を適用します。24週表の金額は維持し、若年割引・年長加算を予算へ反映します。

| 参加者はいくら払い、大会にはいくら必要か | [参加費と予算の説明](IJK2028_予算見通し_全日150人_前後半各100人_20260921.md) |

全員を25〜35歳相当の会員料金で置いた比較値は、収入約1,568万円・支出約1,504万円・差額約64万円です。支出には予備費約161万円を含みます。**この比較値には若年割引も年長加算も反映していません。** 通常予算には350人の年齢内訳が必要なため、説明資料に年齢構成別の仮例を併記しています。施設単価・食数・個室利用数等も仮定です。

主催側から提供された見学報告と招請書下書きをもとに検討しています。それらの原本は今回のアップロードには含めていません。
