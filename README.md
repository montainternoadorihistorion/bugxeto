# IJK 2028 参加費・予算の検討資料

2026年9月23日更新。大本・天恩郷での開催案を、**一般参加150人・7泊8日＋運営スタッフ別枠**へ変更しました。

**まずは[参加費と予算の説明](IJK2028_予算見通し_全日150人_20260923.md)をご覧ください。** 24週間の基本料金と割引規則は維持しています。短期参加は選択肢として残し、今回の基本予算に前半・後半各100人を足しません。

収入は約900万円。音響等の従来枠を残しWi-Fiと暑さ対策を小額化した暫定案は、予定支出約1,040万円です。さらに共通費・参加支援を調整する**未決定の検討案**では、予定支出約815万円、残り約85万円。予備費約98万円を満額確保すると約12万円足りません。予備費の未使用分は支出ではありません。

227人はルーモ館の大部屋205人＋小部屋22人で、小部屋を含みます。今回主催側が見学で確認した個室20室は別館等も含むため、そのまま227人へ上乗せしません。利用許可・部屋割り・単価は引き続き確認事項です。
