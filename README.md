# IJK 2028 参加費・予算の検討資料

2026年9月21日更新。京都・亀岡の大本・天恩郷での開催に向けた検討案です。

**まずは[参加費と予算の説明](IJK2028_予算見通し_全日150人_前後半各100人_20260921.md)をご覧ください。**

全日150人・前半100人・後半100人をもとに、宿泊・食事込みの参加費、年齢別料金、協力者の扱い、ホテル泊、日帰り参加、大会全体の収支を説明しています。

**表示する基本料金は「非会員・雑魚寝・食事付き・全日程」の料金です。** 現在案では従来の会員料金に50ユーロを足して表示し、TEJO個人会員には50ユーロの割引を適用します。参加者の支払額や大会の予算計算は維持します。会員と非会員の差額や寝具等の提供条件には検討中の点があり、説明資料に明示しています。

| 読みたい内容 | 資料 |
|---|---|
| 参加者はいくら払い、大会にはいくら必要か | [参加費と予算の説明](IJK2028_予算見通し_全日150人_前後半各100人_20260921.md) |
| 集金・支払・返金をどう管理するか | [会計運用の検討事項](参考資料/会計運用の検討事項.md) |
| 人数や単価を変えて計算し直す | [計算モデルと計算結果](計算用/) |

比較基準は**収入約1,568万円、支出約1,504万円、差額約64万円**です。支出には約161万円の予備費を含みます。年齢による追加料金や赤字補填を収入に含めずに計算しています。施設単価・食数・個室利用数等は仮定で、確定した収支ではありません。条件による収支の変化も説明資料で確認できます。

主催側から提供された見学報告と招請書下書きをもとに検討しています。それらの原本は今回のアップロードには含めていません。
