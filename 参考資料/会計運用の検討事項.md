# IJK 2028 会計運用の検討事項

2026年9月21日更新／関係者と相談して決めるための案

**予算は「必要な費用と収入の差額」を見るもの、会計運用は「誰が、いつ、どのお金を使えるか」を決めるものです。** 主催側は多少の赤字を許容し、参加費の入金状況に応じて支出規模を調整する方針です。参加費と開催予算は、[参加費と予算の説明](../IJK2028_予算見通し_全日150人_前後半各100人_20260921.md)を使います。本書では、その方針を実行するための集金・支払・返金の仕組みを整理します。

## 1. お金を預かる人と、支払を決める人を決める

大本側の口座等を受け皿にする案を軸に、口座・決済・契約の名義、会計担当、支払の承認者を大本・主催側・TEJOと相談します。大本側が資金を管理し、青年の実行委員会が入金状況と使える額を確認できる形を検討します。

大きな支出と返金は、主催側の会計担当と資金を預かる側の担当が内容を確かめて承認する案です。若者個人の立替や保証に依存せず、赤字が出た場合と余剰金が残った場合の扱いも、募集前に共有します。名義・権限・負担の正式な合意はこれからです。

## 2. 申込みと入金を、同じ番号で結び付ける

一人ごとの登録番号で、申込内容、請求額、入金、決済手数料、返金を対応させます。名義が違う送金や複数人分のまとめ払いも、誰の参加費か分かる記録にします。

| 記録するもの | 必要な理由 |
|---|---|
| 全日・前半・後半・日帰りの参加日 | 登録人数、宿泊数、食数を取り違えないため |
| 年齢区分と一般参加／協力者の区分 | 16歳以下・17〜24歳・25〜35歳・36歳以上の倍率と、協力者の実費・無料を正しく計算するため |
| 申込週・居住国区分・TEJO個人会員等の資格 | 非会員を基準に表示した24週価格表から、年齢倍率を先に掛け、その後で会員割引を反映した支払額を求めるため。patronoの扱いは募集前に確定する |
| 施設内泊・ホテル泊、個室利用 | ホテル泊の参加費から差し引く額、追加料金、部屋割りをそろえるため |
| 請求額・入金額・手数料・入金日 | 参加費収入と実際に口座へ入った額を照合するため |
| 未払い・支払済み・返金済み等の状態 | 参加意向と入金が済んだ参加者を区別するため |

料金は申込内容から自動計算できるようにする案です。ただし、協力者の実費・無料や例外処理は、決めた担当者が確認します。登録をいつ確定するか、未入金時にいつ価格や予約枠を見直すかも、募集要項で明示します。

## 3. 口座残高と、これから使える額を分ける

IJK専用の帳簿で、入金、支払、未払の契約額、返金に備える額、使途が指定されたお金を見られるようにします。

**口座にあるお金の全部を、新しい企画に使えるわけではありません。** これから払う宿泊・食事代や注文済みの費用、返金や急な出費への備え、用途を指定して預かったお金を、先に取り分けます。

例えば、口座に800万円あった場合を考えます。

| 先に取り分けるお金 | 説明用の金額 |
|---|---:|
| これから必ず必要な費用。注文済みで未払いの分も含む | 300万円 |
| 返金や急な出費に備えて残すお金 | 100万円 |
| 別の用途を指定して預かっているお金 | 200万円 |
| **新しい注文などに回せる残り** | **200万円** |

800−300−100−200＝200万円です。同じ費用を二度差し引かないように分類します。これは考え方を説明する例で、今回の実際の残高ではありません。

月ごとの入金予定と、会場・機材・遠足等の予約金、残金、数量変更・取消期限を並べます。入金前に必要な準備費の支払元を整理し、それ以外の追加発注は、入金済み人数と使える額を見て規模を決めます。入金が見込みより少なければ未発注の追加企画・機材仕様・印刷等を縮小・延期し、余裕があれば充実させます。提供を案内した宿泊・食事・通常プログラムや、合意・通知済みの支援は必要額を確保します。

予算に計上する12％の予備費は、予定外の費用への備えです。予算上の「予備費を含む差額」、実際に発生した費用を反映する「最終収支」、その時点の「使える残高」を分けて共有します。多少の赤字を許容する方針のもと、具体的な赤字額と負担の扱いは関係者で詰め、大本からの未合意の補填を入金済みのお金として扱うことはしません。

## 4. 返金の案内と実際の処理をそろえる

参加者都合、重複入金、過払い、査証不許可、主催者都合の中止、遠足の中止・順延など、状況ごとの扱いを募集前に決めます。返金額、手数料、申請期限、必要な確認、実行する担当を、参加者向け案内と会計手順で一致させます。

返金申請と金額計算は省力化しつつ、実際の返金は承認後に行い、元の入金記録と結び付けて残します。返金率や「原則返金なし」を、この文書だけで確定するものではありません。

## 5. 募集前に、小さく動かして確かめる

カード決済や銀行振込など、参加者が使う手段を選び、円で請求する金額、海外からの支払、実際の手数料、返金方法、運営側の閲覧・操作権限を確認します。特定の決済サービスの採用は未確定です。

少額の試験で「申込み→請求→入金→登録番号との照合→必要な返金→帳簿への反映」を通します。参加情報と決済情報は、担当業務に必要な範囲で扱えるようにし、カード情報そのものを主催側の台帳へ記録する運用にはしません。

会計担当には、毎週の入金済み人数、収入、今後の必要費用（未払契約分を含む）、返金・予備費として残す額、追加発注に回せる額、次に発注を決めるものを短く共有してもらう案です。全日150人・前半100人・後半100人、年齢構成5：40：40：15の見込みを出発点に、各参加期間の年齢・会員・居住国・申込週と実際の入金から予算を更新します。予約だけで支払義務や取消料が生じる場合もあるため、未払いの予約分も発注済みとして記録します。
