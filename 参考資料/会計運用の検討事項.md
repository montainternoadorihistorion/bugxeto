# IJK 2028 会計運用の検討事項

2026年9月24日更新／関係者と相談して決めるための案

**予算は「必要な費用と収入の差額」を見るもの、会計運用は「誰が、いつ、どのお金を使えるか」を決めるものです。** 主催側は、参加費の入金に応じて支出規模を調整し、大本への施設使用料100万円と他の開催費用・予備費を確保したうえで、大会全体で150万円以上を残せれば安心という目安を置きます。TEJOとの剰余配分後に日本側へ残る金額ではなく、配分前の大会全体の残額が目標です。参加費と開催予算は、[参加費と予算の説明](../IJK2028_予算見通し_各日150人規模_20260924.md)を使います。本書では、その方針を実行するための集金・支払・返金の仕組みを整理します。

## 1. お金を預かる人と、支払を決める人を決める

**今回大本側から伺った意向は、予算管理は基本的に青年（junuloj）が主体となり、TEJOと連携してTEJOが所有する銀行口座を使い、財政面を管理する方向です。** 大本は宿泊・施設の提供条件や費用を相談する相手として位置付けます。

| 役割 | 今回の方向に沿った分担案 |
|---|---|
| 青年側の実行委員会・大会会計担当 | 予算案、企画ごとの配分、参加者の請求と入金の突合、支出台帳、証憑、残金見込みを管理する |
| TEJO側の会計・口座担当 | TEJOの口座で受払いを扱い、入出金情報を大会会計担当へ共有する。送金の実行・承認権限と報告方法を一緒に決める |
| 大本側 | 修行の宿泊費と施設利用費の対象範囲・単価・利用人数を相談し、請求・支払時期を青年側とすり合わせる |

青年側が使途と日々の予算を管理すること、TEJOが口座を通じた財政管理に関わることを両立させます。青年全員に銀行の送金権限があるという意味ではありません。誰が発注を承認し、誰が振り込み、誰が帳簿と照合するかを決めます。青年側が責任を持って運営する意向から、個人が立替・保証を負うという条件まで推測しません。

2026年9月24日に確認したTEJOのIJK規則では、大会会計担当が提案する予算を理事会が承認し、可能な限りTEJO管理口座で受払いを行い、大会会計担当へ定期的に状況を共有するとされています。他口座が実務上必要な場合の管理・報告、契約の署名前承認も規定されています。今回の口座利用の方向はこれと整合します。具体的な権限・通貨・送金日・手数料は2028年の実務分担として詰めます。[TEJO規則・25頁](https://www.tejo.org/wp-content/uploads/2025/10/2024-08-Reglamentoj-de-TEJO-1.pdf#page=25)

参加費の受領から支払までの流れは、**「参加者の入金 → TEJO側の口座情報を共有 → 青年側が登録番号・請求額・帳簿と照合 → 合意した承認手順で支払 → 帳簿と口座を照合」**とする案です。日本国内の現金・円建て支払が必要な場合は、その受払い方法も事前に決め、同じ帳簿に記録します。

大本が過重な負担をかけないよう配慮してくれる、という主催側の手応えは、低い施設費を検討する根拠になります。一方で、TEJO口座の利用や大本の配慮から、赤字の自動補填や保証額が決まったとは扱いません。募集前に、赤字と残金の扱い・契約主体を関係者で共有します。予算上の残金は、主催者が自由に保持できる利益と確定していません。

### TEJOへ帰属するお金と、口座で預かるお金を分ける

参加者の入金は大会資金として管理し、その全額をTEJOへの分担金とはしません。大本総額100万円の場合の支払い見込みは次のとおりです。

| 支払先・確保するお金 | 金額 | 意味 |
|---|---:|---|
| 大本：宿泊・施設等 | 100.00万円 | 宿泊・会場・必要な音響・通信・食堂運営が含まれる仮定 |
| TEJO：開催分担金 | 31.85万円 | 現在の参加費収入全体を3％の対象とする仮計算 |
| 食事・業者・企画・参加支援等 | 560.32万円 | 食事184.58万円、未配分の参加支援68.15万円などを含む |
| **予定支出の合計** | **692.17万円** | 支援等の未配分枠も含む |
| 予備費12％ | 83.06万円 | 支払先未定の備え |
| **大会全体で残る額** | **286.36万円** | 予備費確保後・剰余金配分前 |

従来のTEJO関連・参加支援100万円は、開催分担金31.85万円と、参加支援・規則上の減免等の未配分枠68.15万円へ分けます。3％の対象は今回の参加費収入全体と仮定しており、小部屋追加・日帰り・返金等の扱いをTEJOと確認します。分担金を100万円へさらに上乗せしません。

役員関連費20万円は滞在・会議等の実費枠です。対象者ごとに宿食・旅費・参加費減免を整理し、一般参加者・無料運営の宿食や支援68.15万円と重ねません。減免を収入側から引く場合は、同額を現金支出にも加えません。

食事代も大本へまとめて支払う場合は、大本への送金見込みが100万円＋食事等184.58万円＝**284.58万円**になります。その他から同額を移すだけで、予定支出合計は変わりません。食事の提供者・請求者は未確定です。

開催後の剰余について、公開規則にはTEJO一般会計・IJK積立・招請者（国別団体の場合）へ各3分の1の配分があります。今回の招請・契約主体への適用条件は未確定です。支払い後の残額を日本側が全額保持すると確定せず、150万円の目標は大会全体の配分前残額で評価します。[TEJO規則・25頁](https://www.tejo.org/wp-content/uploads/2025/10/2024-08-Reglamentoj-de-TEJO-1.pdf#page=25)

上記の剰余配分が適用されるという参考計算では、予備費83.06万円を全額使った後の剰余286.36万円のうち、TEJO一般会計・IJK積立に各95.45万円、両者合計190.91万円です。開催分担金31.85万円も含むTEJO側への帰属額は約222.75万円となります。予備費未使用なら剰余369.42万円、TEJO側の配分計246.28万円、分担金込み約278.13万円です。未払い・返金等の精算後の剰余と契約条件で決まり、確定支払額ではありません。剰余配分を開催費用へ再加算しません。


## 2. 申込みと入金を、同じ番号で結び付ける

一人ごとの登録番号で、申込内容、請求額、入金、決済手数料、返金を対応させます。名義が違う送金や複数人分のまとめ払いも、誰の参加費か分かる記録にします。

| 記録するもの | 必要な理由 |
|---|---|
| 全日・前半・後半・日帰りの参加日 | 登録人数、宿泊数、食数を取り違えないため |
| 年齢区分と一般参加／協力者の区分 | 16歳以下・17〜24歳・25〜35歳・36歳以上の倍率と、協力者の実費・無料を正しく計算するため |
| 申込週・居住国区分・TEJO個人会員等の資格 | 非会員を基準に表示した24週価格表から、年齢倍率を先に掛け、その後で全日の会員割引50ユーロを反映するため。前半・後半は会員・非会員それぞれの全日料金の70％。宿泊追加・ホテル宿泊分の差引きは別に計算する。patronoの扱いは募集前に確定する |
| 施設内泊・ホテル泊、ベッド付き相部屋・一人専有 | 三人相部屋は2,500円／人泊（全日17,500円）、二人相部屋は3,300円（23,100円）、一人専有は5,000円（35,000円）。同じ人に重ねない。全て35歳以下・全日7泊のみ。一人専有はTEJO個人会員限定・応募超過時は抽選。部屋番号・実ベッド数・同室者・専有予約を記録し、室数と人数を区別する。ホテルは原則2,000円／泊引き、最低10,000円・短期は同条件全日まで。参加者への請求と施設への支払原価を分ける |
| 請求額・入金額・手数料・入金日 | 参加費収入と実際に口座へ入った額を照合するため |
| 未払い・支払済み・返金済み等の状態 | 参加意向と入金が済んだ参加者を区別するため |

料金は申込内容から自動計算できるようにする案です。ホテル料金の最低額・短期上限は一人ごとに適用し、平均参加費にまとめて適用しません。同条件とは年齢・会員資格・居住国区分・申込週・換算レートが同じことを指し、円の端数処理も募集時に統一します。ただし、協力者の実費・無料や例外処理は、決めた担当者が確認します。登録をいつ確定するか、未入金時にいつ価格や予約枠を見直すかも、募集要項で明示します。

一人の参加形態が変わった場合は、同じ登録番号の内容を更新し、変更前と変更後を別人として足しません。有料参加者を無料運営へ変更するときは、人数の所属だけでなく、見込んでいた参加費収入も修正します。一般参加・運営・無料日帰りをまたぐ人については、日付と対象費用もそろえ、同じ宿食・名札等を重ねて計上しません。別のサービスに追加費が必要なら、その内容を明示して計上します。

現在の計算モデルは、全日7泊または短期3泊を、すべて施設内か、すべてホテルに泊まる形で集計します。会期途中で宿泊先を変える場合は、各夜の配置を別に作り、全日ホテル用の14,000円差引きをそのまま適用しません。申込後の期間変更で使う申込週、入金済み額との差額、数量変更・返金の扱いは募集前に決めます。会員割引50／35ユーロは宿泊調整前の規則なので、ホテルの最低額・短期上限を適用した最終支払額で案内します。

一人専有の応募が6室を超える場合は、**35歳以下・全日7泊のTEJO個人会員の間で抽選**します。申込時に二人・三人相部屋の希望も聞き、落選者を相部屋へ移せる枠を含めて配分します。落選者と相部屋へ直接申し込んだ人を、合計35床の同じ台帳で管理します。満床後も無制限に振替を約束せず、収まりきらない場合は本人と雑魚寝等を相談します。

宿泊追加分は配室後に確定する案です。すでに一人利用35,000円を受領していれば、二人相部屋へ変更すると11,900円、三人相部屋へ変更すると17,500円の差額を精算します。同じ登録番号の宿泊区分を変更し、人数や収入を重複させません。

通常の寝具・シーツ貸出は修行費用に含め、重ねて請求しません。石鹸・タオルの持参を参加者へ案内します。大本総額に宿泊・会場・機材・通信・食堂運営を含む場合は、含まれる個別支出を除いてから総額を一度だけ記帳します。

## 3. 口座残高と、これから使える額を分ける

青年側が管理するIJK専用の帳簿で、入金、支払、未払の契約額、返金に備える額、使途が指定されたお金を見られるようにします。TEJOの既存口座を使う場合も、その口座全体の残高をIJKの使える額とはせず、IJK分の入出金と残高を識別して共有する案です。

**口座にあるお金の全部を、新しい企画に使えるわけではありません。** これから払う宿泊・食事代や注文済みの費用、返金や急な出費への備え、用途を指定して預かったお金を、先に取り分けます。

例えば、口座に800万円あった場合を考えます。

| 先に取り分けるお金 | 説明用の金額 |
|---|---:|
| これから必ず必要な費用。注文済みで未払いの分も含む | 300万円 |
| 返金や急な出費に備えて残すお金 | 100万円 |
| 別の用途を指定して預かっているお金 | 200万円 |
| **新しい注文などに回せる残り** | **200万円** |

800−300−100−200＝200万円です。同じ費用を二度差し引かないように分類します。これは考え方を説明する例で、今回の実際の残高ではありません。

月ごとの入金予定と、会場・機材・遠足等の予約金、残金、数量変更・取消期限を並べます。入金前に必要な準備費の支払元を整理し、それ以外の追加発注は、入金済み人数と使える額を見て規模を決めます。入金が見込みより少なければ未発注の追加企画・機材仕様・印刷等を縮小・延期し、余裕があれば充実させます。提供を案内した宿泊・食事・通常プログラムや、合意・通知済みの支援は必要額を確保します。

予算に計上する12％の予備費は、予定外の費用への備えです。予算上の「予備費を含む差額」、実際に発生した費用を反映する「最終収支」、その時点の「使える残高」を分けて共有します。安心のための150万円は、必要支出と予備費を取り分けた後に残したいIJK分の目標額です。予備費へ重ねて費用計上したり、TEJO口座全体の残高を充てて達成済みと数えたりしません。150万円を上回る余裕も維持できるよう、未発注分の使途を判断します。大本からの未合意の補填は収入へ入れません。

## 4. 返金の案内と実際の処理をそろえる

参加者都合、重複入金、過払い、査証不許可、主催者都合の中止、遠足の中止・順延など、状況ごとの扱いを募集前に決めます。返金額、手数料、申請期限、必要な確認、実行する担当を、参加者向け案内と会計手順で一致させます。

返金申請と金額計算は省力化しつつ、実際の返金は承認後に行い、元の入金記録と結び付けて残します。返金率や「原則返金なし」を、この文書だけで確定するものではありません。

## 5. 募集前に、小さく動かして確かめる

カード決済や銀行振込など、参加者が使う手段を選び、円で請求する金額、海外からの支払、実際の手数料、返金方法、運営側の閲覧・操作権限を確認します。TEJOの銀行口座を使う方向は今回の共有事項ですが、参加者向けのカード決済サービスや円・ユーロの受領方法は未確定です。既存の決済手数料3.8％は比較用の仮定を維持し、TEJO口座を使うだけで自動的に0円にはしません。送金・両替費をどの枠で負担するかは、徴収通貨と大本等への支払通貨を確認して置き換えます。

少額の試験で「申込み→請求→入金→登録番号との照合→必要な返金→帳簿への反映」を通します。参加情報と決済情報は、担当業務に必要な範囲で扱えるようにし、カード情報そのものを主催側の台帳へ記録する運用にはしません。

会計担当には、毎週の入金済み人数、収入、今後の必要費用（未払契約分を含む）、返金・予備費として残す額、追加発注に回せる額、次に発注を決めるものを短く共有してもらう案です。一般は全日100人＋前半50人＋後半50人、運営は別枠（15人仮置き）、年齢構成5：40：40：15、会員30％・非会員70％の見込みを出発点に、各参加期間の年齢・会員・居住国・申込週と実際の入金から予算を更新します。会員割合は過去の入会状況だけでなく、今回の申込みで実際に割引を使う人から求めます。予約だけで支払義務や取消料が生じる場合もあるため、未払いの予約分も発注済みとして記録します。
