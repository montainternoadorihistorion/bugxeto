# 大本への支払いと、青年・TEJOによる会計管理

2026年9月24日更新。現行の追加縮小検討案について、料金の対象範囲を整理します。

## 今回の資金管理と残額の目標

**目標は、大本への施設使用料100万円と他の開催費用・予備費を確保したうえで、大会全体に150万円以上残すことです。** TEJOとの剰余配分後に日本側へ150万円残す、という意味ではないことを主催側に確認しました。TEJO所有の銀行口座で、IJK分の入出金と残額を区別して管理します。

大本への100万円は、宿泊・施設等の個別積算を置き換える総額を想定します。さらに100万円を上乗せする計算ではありません。予備費12％を確保した後で150万円以上あれば安心、より多く残せれば望ましい、という目安として支出を調整します。

個別積算の残額134.60万円は目標に15.40万円届きません。総額100万円に必要な宿泊・会場・設備・食堂運営が含まれる場合は286.36万円（目標より136.36万円多い）、音響60万円を別払いする場合は219.16万円（同69.16万円多い）です。100万円の対象範囲・実際の入金が仮定どおりなら、目標を満たす見通しです。

## 大本への送金額と、食事代の支払先

食事代も大本へまとめて支払う場合は、大本への送金見込みが100万円＋食事等184.58万円＝**284.58万円**になります。その他から同額を移すだけで、予定支出合計は変わりません。食事の提供者・請求者は未確定です。

大本総額100万円の場合、TEJO開催分担金は仮計算31.85万円、食事・運営・支援等は560.32万円で、予定支出は計692.17万円です。TEJO口座から大本への支払いも行う方向ですが、口座で預かる資金全額をTEJOへ納める意味ではありません。詳しくは[支払先別の収支一覧](../IJK2028_収支一覧_お金の入り方と使い道_20260924.md)を参照してください。

開催後の剰余について、公開規則にはTEJO一般会計・IJK積立・招請者（国別団体の場合）へ各3分の1の配分があります。今回の招請・契約主体への適用条件は未確定です。支払い後の残額を日本側が全額保持すると確定せず、150万円の目標は大会全体の配分前残額で評価します。[TEJO規則・25頁](https://www.tejo.org/wp-content/uploads/2025/10/2024-08-Reglamentoj-de-TEJO-1.pdf#page=25)

## 伺った説明と、主催側の見通し

| 内容 | 位置付け |
|---|---|
| 修行の宿泊費＋施設利用費 | 大本から伺った説明 |
| 通常の寝具・シーツ貸出は修行費用に含む | 主催側の確認。別に加算しない |
| 風呂の石鹸・タオルは持参 | 主催側からの案内事項 |
| 宿泊、会場・光熱・清掃、音響・照明、通信、食堂運営を含め約100万円に収まりそう | やり取りを踏まえた主催側の見通し。正式見積もりではない |
| 予算管理は青年が主体、TEJOが所有する銀行口座を使用 | 共有された実務の方向。担当者・権限等は調整する |

現在は施設内955人泊（一般と運営）、食事3,515食の仮計算です。約100万円は以前の150人×7泊規模の感触を含む見通しで、今回の入替・機材等を明細化した見積額ではありません。ホテル組・日帰りの施設利用や運営15人の宿泊も、提供範囲へ含めて相談します。

## 同じ費用を二度足さない

| 個別積算の対象 | 仮予算 |
|---|---:|
| 施設内宿泊・通常の寝具等 | 955人泊×1,000円＝95.50万円 |
| 会場・光熱・清掃 | 45.00万円 |
| 音響・照明 | 60.00万円 |
| 通信・Wi-Fi | 10.00万円 |
| 食堂運営 | 25.00万円 |
| **計** | **235.50万円** |

これらをすべて大本が総額100万円で提供するなら、**235.50万円を100万円へ置き換えます。** 共通費から140万円を除き、共通費の残り160万円と、大本への100万円を計上します。宿泊95.50万円をさらに足しません。

食事158.175万円と菜食等補完26.40万円は別に維持します。食堂運営は配膳・人員等、食事は食材料・調理済み食事代として仮に分けています。見積もりで両者や菜食対応が一体なら重複を除きます。通常の寝具・シーツ代を追加する前提は取り下げました。

音響・照明や通信が「施設の既存設備を使える」という範囲で、別の機器調達が必要なら不足分を加算します。設備提供・設営・人員・利用日・清掃の範囲を明細でそろえます。

## 現行案の支払い範囲を確認する計算

以下は別の予算方針ではなく、同じ追加縮小案の提供範囲・見積額を変えた確認です。収入は全て1,061.59万円、小部屋20室・41人、日帰りは3日で共通です。

| 支払いの条件 | 予定支出 | 予備費12％ | 予備費を確保した後 |
|---|---:|---:|---:|
| 現行案（個別積算） | 827.67万円 | 99.32万円 | 134.60万円 |
| 大本100万円に宿泊・会場・音響・通信・食堂運営を含む | 692.17万円 | 83.06万円 | 286.36万円 |
| 大本100万円、音響60万円は外注で別途必要 | 752.17万円 | 90.26万円 | 219.16万円 |
| 同じ範囲の大本支払いが120万円 | 712.17万円 | 85.46万円 | 263.96万円 |

235.50万円を100万円へ置換すると予定支出が135.50万円、対応する予備費が16.26万円減り、予備費後の残額は151.76万円増えます。参加者向け料金は変更しません。

## 青年側の管理とTEJO口座を組み合わせる

青年側が予算・企画ごとの使途・請求と入金の突合・支出台帳・証憑を管理し、TEJO側とはTEJO所有の銀行口座での受払い、情報共有、送金手順を決めます。口座全体の残高をIJKの資金とはせず、IJK分を識別します。

TEJOの公開IJK規則にも、予算の理事会承認、可能な限りTEJO管理口座での受払い、大会会計担当への定期的な情報共有、契約の署名前承認が記されています。2026年9月24日に再確認しました。2028年の具体的な権限や手数料は実務調整として残します。[TEJO規則・25頁](https://www.tejo.org/wp-content/uploads/2025/10/2024-08-Reglamentoj-de-TEJO-1.pdf#page=25)

大本の配慮やTEJO口座の利用を、赤字の自動補填・保証の合意とは扱いません。補填収入は0円のまま、入金に合わせて未発注の支出を決めます。
