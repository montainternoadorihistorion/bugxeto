# 全日150人・8日間への変更と検証結果

2026年9月23日。旧350人案の検算結果を、新しい150人案の根拠として流用せず、改めて積算しました。

**150人には36歳以上も含み、運営は別枠です。基本予算に短期200人を加えません。** 年齢は8／60／60／22人へ丸め、会員30％、無料運営15人、ホテル22人、有料個室20人を置いています。スタッフ人数・配置・個室販売数は仮定です。

| 確認事項 | 結果 |
|---|---|
| 24週×4区分の価格表 | 旧説明資料の96数値から読み取り、新表と一致 |
| 年齢4区分・会員2区分・期間3区分 | 基本料金とホテル料金を4,608条件で独立計算して一致 |
| 最低額と短期上限 | 個別に最低1万円、短期は同条件全日まで。従来の方針を維持 |
| 予算の積算 | 16ケース全て、別のDecimal計算で収入・費目・予備費・差額が一致（誤差0.000001円未満） |
| 宿泊・食事 | 施設内143人×7泊＝1,001人泊、165人×21食＝3,465食を確認 |

計算が一致することと、施設単価・需要・支援額が確定していることは別です。追加縮小案は共通費300万円、TEJO等100万円、遠足支援30万円という未決定の提案です。料金の引上げを織り込まず、原価や参加構成が変わる場合を比較しています。

今回、227人の表に小部屋22人が含まれることが分かりました。表の「1-lita・2室・4人」は不整合が残ります。個室20室は別館も含むため、227人へ単純に加算しません。計算上の定員確認には資料の227を使っていますが、実際の予約可能数や募集上限を確定した意味ではなく、自動ホテル振替も既定では行いません。

一人一室として個室20人を上限に仮置きしましたが、関係者用の取り置き等があれば販売上限を下げます。個室の追加原価、食事原価、無料来場の人数は重要な未確定項目です。年齢・国・申込時期・会員割合の相関や、会期中にホテルと施設を移る泊まり方は基本予算に含めていません。実名簿では各人・各夜・各食に分けます。

無料来場300人日は以前からの費用確保用の仮定です。3日へ均等なら100人／日となり、宿泊プラン165人＋有料日帰り40人と同時に来れば305人になります。これを予測として断定せず、ホール・受付・食堂の数量へ分けます。参加費免除・支援・無料運営・日帰りで同じ人を二重計上しない点も維持します。
