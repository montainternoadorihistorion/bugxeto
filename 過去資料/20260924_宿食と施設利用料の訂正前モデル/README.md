# 訂正前モデルv10（現在の予算には使用しない）

このモデルには、宿泊1,000円・食事450円の独自単価、根拠のない菜食補完費26.40万円、宿食を含む大本総額100万円という誤った解釈が含まれます。2026年9月24日に訂正しました。

確認した方針は、**大本公式の修行単価による宿泊・食事代＋施設利用料100万円**です。食事は大本の食堂で提供される前提です。公式単価は宿泊850円、朝食250円、昼・夕食各400円。
