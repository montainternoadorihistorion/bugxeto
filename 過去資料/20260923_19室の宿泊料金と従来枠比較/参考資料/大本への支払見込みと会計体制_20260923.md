# 大本への支払見込みと、青年・TEJOによる会計管理

2026年9月23日追記。今回主催側から共有された見学後の情報を反映しています。

## 1. 大本から伺ったことと、主催側の見込み

| 内容 | 現時点の位置付け |
|---|---|
| 大本への支払いは「修行の宿泊費＋施設利用費」 | 主催側が大本から伺った説明 |
| 150人×7泊程度なら約100万円でも受け入れてもらえるかもしれない | 主催側の感触に基づく見込み。大本からの正式提示額ではない |
| 過重な負担をかけないよう配慮してくれると思う | やり取りを踏まえた主催側の見立て。補填・保証額の合意とは別 |
| 予算管理は基本的に青年（junuloj）が主体 | 大本側から伺った意向 |
| TEJOと連携し、TEJOが持つ銀行口座で財政面を管理する方向 | 主催側から共有された実務の方向。担当者・送金権限等はこれから整理 |

大会は7泊8日、全日100人＋前後半各50人、各日一般約150人＋運営別枠です。大本への約100万円という見込みは以前の150人×7泊規模の感触であり、今回の955人泊や入替を正式に見積もった額ではありません。施設利用は宿泊人数だけでなくホテル組・日帰りも含めて範囲を確認します。

以下は、**約100万円が宿泊費と施設利用費の合計で、食事は別の場合**の条件付き比較です。100万円の対象範囲は確認中であり、従来の個別積算を一律に100万円へ置き換えて確定したものではありません。

## 2. 宿泊・施設費を二度足さない

個別積算の追加縮小案は、施設内955人泊×1,000円＝95.50万円の宿泊費と、会場・光熱・清掃45万円、合計140.50万円です。100万円がこの両方を含むなら140.50万円を100万円へ置き換えます。食事158.175万円は別に維持します。個室等の追加原価は未見積もりで0円を仮置きし、総額外と分かれば加算します。

光熱・清掃等が含まれない場合に10万円を別に残す例も比較します。10万円は確定見積もりではありません。運営人数や前後泊、入替に伴う清掃・寝具の扱いも確認します。

全て収入1,050.25万円、全日100人＋前後半各50人、小部屋6・6・7室配分です。音響60万円・Wi-Fi10万円・暑さ対策約5万円は維持します。

追加縮小案で合計100万円に収まる場合、予備費後は約169万円です。個別積算の約124万円から45.36万円改善します。予定支出40.50万円と、それに対応する予備費4.86万円が減るためです。今回の参加構成と小部屋の販売が成立し、その他の縮小項目も実施できる場合の見通しです。

参加者向け料金はベッド付き相部屋2,500円／人泊、または一人専有5,000円／人泊の追加です。ホテル差引き2,000円／人泊も維持し、大本への支払原価とは分けます。


## 4. 青年主体の管理とTEJO口座を組み合わせる

青年側が大会の予算、企画ごとの使途、請求・入金の突合、支出台帳、証憑、使える残額を管理し、TEJO側とは既存の銀行口座での受払い・情報共有・送金手順を決めます。大本は宿泊・施設の条件と費用を相談する相手です。

TEJOのIJK規則も、可能な限りTEJO管理口座で受払いし、大会会計担当へ定期的に情報を共有する形です。予算の理事会承認・契約の署名前承認もあるため、青年側の判断とTEJO側の承認・送金をどうつなぐかを整理します。2028年の具体的な権限と手順が決まったとまでは扱いません。[TEJO規則・25頁](https://www.tejo.org/wp-content/uploads/2025/10/2024-08-Reglamentoj-de-TEJO-1.pdf#page=25)

既存口座の全残高をIJKのお金として数えず、IJK分の入出金を識別する帳簿を共有します。会計・監査費や決済手数料は口座を使うだけで不要にはならないため、今回は自動で減らしません。青年主体という意向から、個人の立替・保証を要求する条件も追加しません。
